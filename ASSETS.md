## Why a procedural mannequin?

The 20-hour plan's hour-3 decision gate says to fall back to "a known compatible rigged GLB" if asset import is a problem. Mixamo and similar libraries need an interactive login and have terms that limit redistribution in a public repo. A generated mannequin avoids both problems:

- the licence is unambiguous,
- both clips share one skeleton by construction, so retargeting isn't needed,
- phase markers are known exactly because the motion is authored as data.

The trade-off is visual. It is a stylised wooden-mannequin figure with rigid segments, not a realistic human.

## Technical record (README "Assets and rigging rules" §4)

Run `npm run assets:build` to regenerate the GLB. The build writes `public/models/forma-mannequin.meta.json` with the measured values. Run `npm run assets:validate` to re-check the GLB.

- **Coordinate system:** metres, +Y up, the character faces +Z, and the character's left is +X.
- **Scale:** about 1.75 m tall. Hips at 0.97 m, ankles at 0.08 m.
- **Bind pose:** standing, with arms hanging straight down and all joint rotations at identity.
- **Hierarchy:** `Root › Hips › Spine › Chest › Neck › Head`. The arms (`{Left,Right}UpperArm › LowerArm › Hand`) hang from `Chest`. The legs (`{Left,Right}UpperLeg › LowerLeg › Foot`) hang from `Hips`.
- **Skinning:** rigid. Every vertex is 100% weighted to one bone. Joint spheres hide the seams.
- **Clips:** each clip drives every joint, so switching clips never leaves a stale pose.
- **Build-time QA** (the build fails if any check fails):
  - ankle drift < 5 mm,
  - the lowest skinned vertex stays within −1…+2 cm of the floor in every frame,
  - hands (and the curl's inner dumbbell plates) never penetrate the torso or thighs.

## Motion review status

The squat targets a beginner, just-above-parallel depth at the bottom marker:

- thighs about 12° above horizontal,
- shins about 34° forward,
- trunk lean about 38°,
- arms reaching forward to counterbalance.

The curl goes from about 12° to about 140° of elbow flexion, with the upper arms by the sides.

These are general demo ranges. A qualified coach has **not** reviewed them yet. Both the cues and the motions are marked `pending_expert_review` in the catalog.

## Replacing the avatar

A licensed or personalised GLB can be swapped in when it meets these conditions:

1. It contains clips named `squat` and `biceps_curl`, or the `clipName` values in `src/lib/exercises/catalog.ts` are updated to match.
2. Phase markers in the catalog are re-authored against the new clips.
3. `npm run assets:validate path/to/model.glb` passes.
4. The model credits and licence terms are added to this table.
